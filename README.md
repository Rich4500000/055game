# 科技守卫家园 - 055型南昌舰指挥模拟器

这是一个使用 Python 3.10+ 和 Pygame 2.5+ 编写的“055型南昌舰防空反导指挥模拟器”，用于青少年国防科技素养大赛创意设计赛展示。

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 操作说明

- `S`：开始任务
- 鼠标点击雷达目标：选择目标
- `1`：发射海红旗-9B远程防空导弹，射程260km
- `5`：发射海红旗-16B中程防空导弹，射程160km（比赛演示装载）
- `2`：发射鹰击-18反舰导弹，射程600km
- `3`：发射鹰击-21高超音速反舰导弹，射程1500km
- `4`：发射长剑-10对陆攻击巡航导弹，射程超1000km
- `F` 或点击“编队命令”：显示/隐藏编队指挥态势
- `N`：当前波次清空后搜索新目标
- `R`：游戏结束后重新开始
- `Esc`：退出

## 已实现检查项

- 雷达扫描线动画
- S波段发现目标，X波段黄色锁定框精确跟踪
- 鼠标交互选择目标，按 `1` / `2` 发射导弹
- 导弹追踪曳光动画与命中爆炸粒子
- 1130近防炮自动末端拦截逻辑
- 编队指挥示意图与威胁方向箭头
- 直-20直升机环绕起降动画
- 战斗简报、时间、拦截率与鼠标悬停工具提示

## 分文件说明

- `main.py`：主程序入口、游戏循环、事件处理、状态切换。
- `config.py`：窗口、颜色、055南昌舰真实参数、弹药与得分规则。
- `radar.py`：`RadarSystem` 与 `Target`，负责双波段雷达扫描、目标波次和跟踪。
- `weapons.py`：`WeaponSystem`、导弹追踪、爆炸粒子、得分。
- `defense.py`：`CloseInDefenseSystem`，负责1130近防炮自动拦截。
- `battlefield.py`：`BattlefieldManager`，负责全景沙盘战场事件，包括电子干扰、低空突防、编队协防、补给和损管。
- `ui.py`：`DefenseUI`，负责全部界面、按钮、简报、编队图和工具提示。

## 玩法增强

- 全景战场沙盘：展示航母编队、055南昌舰、护卫舰、敌方空中/导弹/海面威胁。
- 随机战场情景：电子干扰会导致X波段锁定框短暂闪断；低空突防会新增来袭导弹；编队协防可自动拦截一个威胁。
- 支援事件：补给窗口可恢复少量弹药，损管小组可恢复舰艇生命值。
- 比例尺：1000km态势圈由055、航母编队和预警机数据链共同维持；数据链离位或受压制时，界面回落到055本舰雷达态势圈。
- 分层打击：HHQ-9B远程防空，HHQ-16B中程防空，YJ-18反舰，YJ-21高超音速反舰，CJ-10对陆打击。
- 分层防御：054A伴随舰协防，HQ-10自动近程拦截，L-DEW激光防空演示模块照射低成本目标，1130近防炮末端拦截。
- 电子战：ECM会降低数据链质量、缩短有效探测距离、制造假目标并让跟踪框产生噪声，而不是简单随机掉锁。

## 资产清单

本项目默认不依赖外部图片或声音文件：

- 图形：全部通过 `pygame.draw` 绘制。
- 字体：使用系统默认中文字体候选，如微软雅黑、黑体、苹方；若缺失则退回 Arial。
- 音效：由程序通过 `pygame.sndarray` 和 `numpy` 合成短音效。
- 可选目录：如后续加入外部资源，可建立 `images/` 与 `sounds/` 文件夹。

## Windows 可执行文件打包方案

推荐版本：

```bash
pip install pyinstaller==6.6.0 pygame>=2.5 numpy>=1.24
```

基础打包命令：

```bash
pyinstaller --onefile --windowed --name "055_Nanchang_Command_Simulator" main.py
```

如果后续加入外部资产，请使用：

```bash
pyinstaller --onefile --windowed --name "055_Nanchang_Command_Simulator" ^
  --add-data "images;images" ^
  --add-data "sounds;sounds" ^
  main.py
```

注意事项：

- Windows 下 `--add-data` 源路径和目标路径之间使用分号 `;`。
- macOS/Linux 下分隔符改为冒号 `:`。
- 若答辩电脑没有音频设备，程序会自动跳过音效，不影响演示。
- 打包后可执行文件位于 `dist/055_Nanchang_Command_Simulator.exe`。
